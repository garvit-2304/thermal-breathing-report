# Thermal breathing research: progress report

LaTeX progress report for TAs and mentors on breathing-rate detection and facial breathing-region segmentation from thermal video.

The report covers data preparation, signal-based and learned estimators, tracking, segmentation, measured results, limitations and next steps. Kwon et al. and JoulesEye are the two research references.

## Build

Open `main.tex` in Overleaf or compile with a standard LaTeX installation:

```sh
pdflatex main.tex
pdflatex main.tex
```

This repository contains the report source only. Dataset files, participant images and experiment artifacts are not included. Project-relative evidence paths in the report refer to the original research workspace.
